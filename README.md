# assignmentJavaTDD

Test Driven Development (TDD) implementation of a Calculator in Java.

---

## Technologies Used

- Java 11 (OpenJDK 11.0.25)
- JUnit 4 for unit testing
- Maven (for build and dependency management)

---

## Project Overview

This project demonstrates a Calculator application developed using Test Driven Development principles.  
The Calculator supports addition of numbers from strings with custom delimiters and handles exceptions such as negative numbers.

---

## Prerequisites

- Java 11 (OpenJDK 11.0.25)
- Maven 3.x
- IDE of your choice (IntelliJ IDEA, Eclipse, VS Code, etc.)
